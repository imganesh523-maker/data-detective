    About Data Detective

    A story-driven game that teaches Python and Pandas data analysis from absolute basics to anomaly detection. Every clue hides in a dataset, and every answer is checked by running your real Python code - in your browser, with Pyodide.

    No login, no backend, no tracking. Your progress lives only in this browser (localStorage).
